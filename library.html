Beginner's Learning Guide

Fundamentals of HTML and CSS

Learning the structure, style, and layout of web pages

Learning Objectives

At the end of this learning guide, students should be able to:

  • Explain the roles of HTML, CSS, and JavaScript in web development.
  • Identify the basic structure of an HTML document.
  • Use common HTML elements to organize text, images, links, lists, tables, and forms.
  • Apply inline, internal, and external CSS.
  • Use CSS selectors and common styling properties.
  • Explain the CSS box model and create simple layouts using Flexbox.
  • Develop a basic personal profile webpage using HTML and CSS.

1. Introduction to Web Development

Web development is the process of creating websites and web applications that people access through web browsers such as Google Chrome, Microsoft Edge, and Firefox.

TechnologyFull NameMain PurposeExamples
HTMLHyperText Markup LanguageDefines webpage structure and content.Headings, paragraphs, images, links, tables
CSSCascading Style SheetsControls the appearance and layout of a webpage.Colors, fonts, spacing, borders, layouts
JavaScriptJavaScriptAdds behavior and interactivity.Menus, pop-ups, form validation, dynamic content
A simple analogy

Think of a website as a house: HTML is the structure, CSS is the paint and decoration, and JavaScript provides interactive features and functionality.

Part I — HTML Fundamentals

2. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure and content of webpages. HTML uses elements, commonly written with opening and closing tags, to tell the browser how content is organized.

3. Basic HTML Document Structure

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Website</title>
</head>
<body>
  <h1>Welcome to HTML</h1>
  <p>This is my first webpage.</p>
</body>
</html>
ElementPurpose
<!DOCTYPE html>Declares that the document uses HTML5.
<html>Root element of the HTML document.
<head>Contains metadata and information about the webpage.
<meta>Provides character encoding and viewport settings.
<title>Sets the title displayed in the browser tab.
<body>Contains the visible webpage content.
<h1>Defines a top-level heading.
<p>Defines a paragraph.

4. HTML Tags and Elements

An HTML element usually consists of an opening tag, content, and a closing tag. For example, in <p>Hello, World!</p>, <p> is the opening tag, the words are the content, and </p> is the closing tag.

4.1 Heading Tags

HTML provides six heading levels, from <h1> to <h6>. Use headings in a logical order to organize page content.

<h1>Main Heading</h1>
<h2>Subheading</h2>
<h3>Heading Level 3</h3>
<h4>Heading Level 4</h4>
<h5>Heading Level 5</h5>
<h6>Heading Level 6</h6>

4.2 Paragraph and Text Formatting

<p>This is a paragraph.</p>
<strong>Important text</strong>
<b>Bold text</b>
<em>Emphasized text</em>
<i>Italic text</i>
<u>Underlined text</u>
<mark>Highlighted text</mark>
<del>Deleted text</del>

Use semantic elements such as <strong> and <em> when meaning or importance matters, rather than choosing elements only for their visual appearance.

4.3 Links

The anchor element creates a hyperlink. The href attribute specifies the destination.

<a href="https://www.google.com">Visit Google</a>

4.4 Images

The img element embeds an image and does not need a closing tag.

<img src="picture.jpg" alt="A description of the picture" width="300">
  • src specifies the image file or image URL.
  • alt provides alternative text describing the image.
  • width and height specify image dimensions.

4.5 Ordered and Unordered Lists

<h2>My Subjects</h2>
<ol>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ol>

<h2>My Hobbies</h2>
<ul>
  <li>Reading</li>
  <li>Coding</li>
  <li>Gaming</li>
</ul>
TagPurpose
<ol>Creates a numbered list.
<ul>Creates a bulleted list.
<li>Defines an item in a list.

4.6 Tables

<table>
  <tr>
    <th>Name</th>
    <th>Course</th>
  </tr>
  <tr>
    <td>Juan</td>
    <td>BSIT</td>
  </tr>
</table>
TagPurpose
<table>Creates a table.
<tr>Creates a table row.
<th>Defines a header cell.
<td>Defines a data cell.

4.7 Forms and Input Elements

<form>
  <label for="fullname">Full Name:</label>
  <input type="text" id="fullname" name="fullname"
         placeholder="Enter your name">
  <label for="email">Email:</label>
  <input type="email" id="email" name="email">
  <label for="password">Password:</label>
  <input type="password" id="password" name="password">
  <button type="submit">Submit</button>
</form>
Input TypePurpose
textAccepts a line of text.
emailAccepts an email address and checks its basic format.
passwordMasks the entered password.
numberAccepts numeric input.
dateAllows the user to select a date.
radioAllows one option to be selected from a group.
checkboxAllows one or more options to be selected.
fileAllows the user to select a file.

Part II — CSS Fundamentals

5. What is CSS?

CSS stands for Cascading Style Sheets. It describes how HTML elements should look on screen, on paper, or in other media. CSS can control colors, fonts, spacing, borders, positioning, and responsive layouts.

6. Three Ways to Apply CSS

6.1 Inline CSS

<h1 style="color: blue; text-align: center;">
Welcome to CSS
</h1>

6.2 Internal CSS

<head>
  <style>
    h1 { color: blue; text-align: center; }
    p { color: green; }
  </style>
</head>

6.3 External CSS

External CSS is stored in a separate .css file and connected with a link element.

<link rel="stylesheet" href="style.css">
h1 {
  color: blue;
  text-align: center;
}

p {
  color: green;
  font-size: 18px;
}

7. CSS Syntax

selector {
  property: value;
}
h1 {
  color: red;
  font-size: 30px;
}

The selector identifies what to style, the property identifies the style feature, and the value specifies the setting.

8. Common CSS Selectors

8.1 Element Selector

p {
  color: blue;
}

Selects all paragraph elements.

8.2 Class Selector

<p class="highlight">Important information</p>

.highlight {
  color: red;
  font-weight: bold;
}

A class selector starts with a period and can be reused on multiple elements.

8.3 ID Selector

<h1 id="title">My Website</h1>

#title {
  color: green;
  text-align: center;
}

An ID should be unique within a page.

9. Common CSS Properties

9.1 Text Styling

h1 {
  color: blue;
  font-size: 32px;
  font-family: Arial, sans-serif;
  font-weight: bold;
  text-align: center;
}
PropertyFunction
colorChanges text color.
font-sizeChanges text size.
font-familySpecifies the typeface.
font-weightControls text thickness.
text-alignAligns text.
text-decorationAdds or removes text decoration.

9.2 Background Styling

body {
  background-color: lightblue;
}

h1 {
  color: #ffffff;
  background-color: #2563eb;
}

9.3 Borders

div {
  border: 2px solid black;
}

The border shorthand follows this pattern: width, style, and color. Common styles include solid, dashed, dotted, and double.

9.4 Margin and Padding

.card {
  margin: 20px;
  padding: 15px;
  border: 2px solid black;
}

Margin creates space outside an element's border. Padding creates space between the content and the element's border.

9.5 Width and Height

.box {
  width: 300px;
  height: 200px;
}

Width and height control an element's dimensions. Useful sizing values include pixels, percentages, rem, and viewport units.

Part III — CSS Layout and Design

10. CSS Display Property

.block { display: block; }
.inline { display: inline; }
.flex { display: flex; }
.grid { display: grid; }
Display ValueDescription
blockStarts on a new line and generally takes the available width.
inlineFlows with surrounding text and takes only the space it needs.
inline-blockFlows inline while allowing width and height to be set.
flexCreates a flexible one-dimensional layout.
gridCreates a two-dimensional grid layout.
noneRemoves the element from the layout.

11. CSS Flexbox

<div class="container">
  <div class="box">HTML</div>
  <div class="box">CSS</div>
  <div class="box">JavaScript</div>
</div>

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 20px;
}

.box {
  background-color: lightblue;
  padding: 30px;
}

12. CSS Hover Effect

<button class="btn">Click Me</button>

.btn {
  background-color: blue;
  color: white;
  padding: 12px 25px;
  border: none;
  cursor: pointer;
}

.btn:hover {
  background-color: darkblue;
}

13. Border Radius and Box Shadow

.card {
  background-color: white;
  padding: 20px;
  border-radius: 12px;
  box-shadow: 0 4px 10px rgba(0, 0, 0, 0.2);
}
  • border-radius rounds the corners of an element.
  • box-shadow adds a shadow around an element.

Part IV — Hands-On Laboratory

14. Create Your First Personal Profile Webpage

Objective: Apply basic HTML tags and CSS properties to create a simple personal profile webpage.

Expected Content

  • Student name and course/program
  • A short About Me paragraph
  • A list of at least three hobbies
  • A Contact Me button
  • A background color and readable text styling
  • A profile container with padding, rounded corners, and a subtle shadow

Step 1. Create the Project Folder

Open Visual Studio Code. Create a folder named HTML-CSS-Activity. Inside the folder, create index.html and style.css.

Step 2. Write the HTML Code

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Profile</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="profile">
    <h1>Juan Dela Cruz</h1>
    <h3>BSIT Student</h3>
    <h2>About Me</h2>
    <p>Hello! I am a student learning HTML and CSS.
       I enjoy coding and creating websites.</p>
    <h2>My Hobbies</h2>
    <ul>
      <li>Coding</li>
      <li>Playing Online Games</li>
      <li>Reading</li>
    </ul>
    <button>Contact Me</button>
  </div>
</body>
</html>

Step 3. Write the CSS Code

body {
  background-color: #f1f5f9;
  font-family: Arial, sans-serif;
}

.profile {
  background-color: white;
  width: 400px;
  margin: 50px auto;
  padding: 25px;
  border-radius: 12px;
  box-shadow: 0 4px 10px rgba(0, 0, 0, 0.1);
}

h1 {
  color: blue;
  text-align: center;
}

h3 {
  text-align: center;
  color: gray;
}

button {
  background-color: blue;
  color: white;
  padding: 12px 20px;
  border: none;
  border-radius: 5px;
  cursor: pointer;
}

button:hover {
  background-color: darkblue;
}

Step 4. Run and Improve the Webpage

  • Save both files.
  • Open index.html in Google Chrome or use the Live Server extension in Visual Studio Code.
  • Change the sample name to your own name.
  • Write your own About Me paragraph and hobbies.
  • Experiment with the background color, font size, and button design.
  • Check that the page is readable on a smaller screen.

Teaching Tip

Teach HTML structure before introducing CSS. First, allow students to understand how HTML elements organize content. Then demonstrate how CSS changes the appearance and layout of those elements. Encourage students to type, run, and modify the code themselves.
